# Decision Document: Clip Generation MVP for Бро.Хит

## Executive Summary

Рекомендуемый MVP — **гибридный loop-based pipeline**: стилизация фото → короткий animated loop → бесшовное повторение на всю песню → караоке overlay. Это единственный вариант, который реально укладывается в $0.30–$0.80 за клип при стабильном качестве.

---

## Сравнение 3 архитектурных вариантов

### Вариант 1: Ultra-Cheap (Static Image + Motion Design)

**Идея:** Одно стилизованное изображение из фото пользователя. Никакой video diffusion. Вся "анимация" — это camera motion (Ken Burns effect), частицы, light flares, параллакс слоёв.

| Параметр | Оценка |
|----------|--------|
| Себестоимость | **$0.05–$0.15** за клип |
| Качество | ⭐⭐ — выглядит как slideshow с эффектами |
| Стабильность | ⭐⭐⭐⭐⭐ — минимум точек отказа |
| Wow-эффект | ⭐⭐ — быстро приедается |
| Сложность | Низкая |

**Pipeline:**
1. Image generation (SDXL/Flux) — $0.02–$0.05
2. FFmpeg composition с Ken Burns + particles — $0.01–$0.02 (CPU)
3. Karaoke overlay — $0.01
4. Alignment — $0.01–$0.05

**Плюсы:**
- Минимальная себестоимость
- Можно запустить за неделю
- Почти нет GPU-зависимости для рендера

**Минусы:**
- Не выглядит как "клип" — скорее как animated poster
- Пользователи быстро поймут, что видео статичное
- Низкая perceived value → низкая конверсия
- Трудно оправдать даже минимальную цену для пользователя

**Вердикт:** Подходит только как fallback или как бесплатная tier.

---

### Вариант 2: Recommended MVP (Loop-Based Hybrid)

**Идея:** Стилизованное изображение → короткий animated loop 5–12 сек (image-to-video) → бесшовное повторение с вариациями → караоке.

| Параметр | Оценка |
|----------|--------|
| Себестоимость | **$0.30–$0.80** за клип |
| Качество | ⭐⭐⭐⭐ — выглядит как animated music video |
| Стабильность | ⭐⭐⭐⭐ — контролируемый pipeline |
| Wow-эффект | ⭐⭐⭐⭐ — реально впечатляет при первом просмотре |
| Сложность | Средняя |

**Pipeline:**
1. Face detection + segmentation — $0.001 (CPU)
2. Image stylization (SDXL/Flux IP-Adapter) — $0.03–$0.08
3. Loop animation (SVD / Kling / MiniMax) — $0.10–$0.40
4. Karaoke alignment (Whisper + forced alignment) — $0.02–$0.05
5. FFmpeg composition + motion design — $0.02–$0.05 (CPU)
6. Storage + transfer — $0.01–$0.03

**Плюсы:**
- Реальное движение персонажей
- Бесшовный loop выглядит как полноценная сцена
- Маскировка повторяемости через zoom/pan/color shifts
- Возможность 2–3 разных loop-сцен (куплет/припев) за доп. $0.20–$0.40
- Управляемый cost ceiling

**Минусы:**
- При внимательном просмотре loop заметен (но караоке отвлекает)
- Нужен GPU для image-to-video генерации
- Зависимость от внешних API (Kling, Runway, etc.) или self-hosted SVD

**Вердикт: ✅ РЕКОМЕНДУЕТСЯ.** Лучший баланс качество/стоимость/стабильность.

### Вариант 3: Premium (Multi-Scene AI Video)

**Идея:** 4–8 уникальных video-diffusion сцен по 5–10 секунд, монтаж как в настоящем клипе, разные ракурсы и декорации.

| Параметр | Оценка |
|----------|--------|
| Себестоимость | **$2.00–$8.00** за клип |
| Качество | ⭐⭐⭐⭐⭐ — ближе к настоящему music video |
| Стабильность | ⭐⭐ — много точек отказа, inconsistency между сценами |
| Wow-эффект | ⭐⭐⭐⭐⭐ |
| Сложность | Высокая |

**Pipeline:**
1. Scene planning (LLM) — $0.01–$0.05
2. Multiple stylized keyframes — $0.15–$0.40
3. Multiple video generations — $1.00–$5.00
4. Character consistency across scenes — нерешённая проблема
5. Editing / transitions — $0.10–$0.20
6. Karaoke — $0.05

**Плюсы:**
- Максимальный wow-эффект
- Уникальный контент

**Минусы:**
- Выход за бюджет $1 за клип
- Character consistency между сценами — нерешённая проблема в 2024–2026
- Высокий процент брака: 20–40% генераций дают плохой результат
- Нужны ретраи → ещё дороже
- Сложность pipeline × 5 по сравнению с Вариантом 2
- Latency 15–30 минут вместо 3–5

**Вердикт:** Не подходит для MVP. Возможен как premium upsell в Phase 4.

## Итоговое решение

| Критерий | Вариант 1 | **Вариант 2** ✅ | Вариант 3 |
|----------|-----------|----------------|-----------|
| Себестоимость | $0.05–0.15 | **$0.30–0.80** | $2–8 |
| Wow-эффект | Низкий | **Высокий** | Очень высокий |
| Стабильность | Отличная | **Хорошая** | Плохая |
| Time to market | 1–2 недели | **4–6 недель** | 3–4 месяца |
| Масштабируемость | Отличная | **Хорошая** | Проблемная |

**Выбор: Вариант 2 — Loop-Based Hybrid MVP.**

Вариант 1 используется как fallback при сбое генерации loop.
Вариант 3 — roadmap на Phase 4 (premium tier).

## Почему НЕ полноценный AI video pipeline

1. **Стоимость.** Генерация 2–3 минут уникального video diffusion стоит $5–$20. При сотнях клипов в день это $1500–$6000/день.
2. **Консистентность.** Нельзя гарантировать, что персонаж на сцене 1 и сцене 5 выглядит одинаково.
3. **Брак.** 30–50% генераций video diffusion дают артефакты, требуют ретраев.
4. **Latency.** 20–40 минут vs 3–7 минут для loop-based.
5. **Сложность.** Нужен scene planner, consistency controller, editor — каждый с своими failure modes.

Loop-based подход решает все эти проблемы: одна хорошая генерация переиспользуется, караоке отвлекает от повторяемости, motion design добавляет вариативность.
